# Packet: the 象 stepper as a TypeScript/HTML page — `web/stepper/`

From claude-16, 2026-10-16. Repo: /home/joe/code/futon3c, branch master, work in place (the files are new; do not touch anything outside `web/stepper/` except as the acceptance says).

## Goal

Port the read-only Emacs side window `*象 stepper*` (`emacs/turn-stepper.el`, the rendering is lines 92–382; read it first, it is the spec) to a framework-free page: `web/stepper/stepper.ts` compiled once to `web/stepper/stepper.js` (ES module, no bundler, `tsc`), `web/stepper/index.html`, `web/stepper/test_stepper.mjs`. Same approach as the scope view beside it (`web/scopes/`: read `PACKET-scopes-view.md` there for the conventions, and reuse its page style).

The stepper shows one **frame** per operator turn of a session. The frames are produced by `scripts/turn_frames.py` (docstring at the top gives the frame shape; the fixture `web/stepper/fixtures/frames-claude-16-00e653e3.json` has 12 live frames from claude-16's session). Frame fields: `turn {evidence_id, at, text}`, `parse {status, fragments[]}`, `operators {hits[], cues_without_operator[]}`, `patterns {matched, rejected, proposed_by_parent}`, `happened[]`, optional `ports {closed_this_turn[], still_open[]}`, optional `record {id, turn_id, agent_id, session_id}`, and optional `memory` (see below; no frame carries it yet).

## What the page does

1. **Loads frames.** `?session=<id>` fetches `${base}/api/alpha/xiang/frames?session=<id>&limit=<n>` (`base` from `?base=`, default same origin; `limit` from `?limit=`, default 60) and reads `.frames` from the JSON object `{ok, session, frames, elapsed_ms}`; on `ok:false` or a network error it shows the `reason` and stays usable with whatever it last had. Without `?session=` it loads `fixtures/frames-claude-16-00e653e3.json` (a bare array). No fetch inside `renderStepper`; `index.html` does the fetch.
2. **Ready frames.** Port `turn-stepper--ready-frames`: drop trailing frames whose `parse.status` is neither `analyzed` nor `drafted-provisional`; an older never-read turn stays and shows as missing.
3. **One frame at a time**, exactly the Emacs sections and order: a header line `frame i/n · <first 8 chars of session> · <parse.status>`; **SAID** (time, text); **OPERATORS** (port `--render-operators`: ibol, quoted word, and whether it falls inside one of 象's marks and agrees); **PARSE** (port `--render-parse` and `--render-fragments`: `[combined]` or `disagree: a / b`, the fragment text with each cue underlined, wavy purple, the sources line `source→intent?`; `drafted-provisional` gets the italic grey note "小象, provisional — 象's reading pending" and the same styling on its labels); **PATTERNS** (matched, proposed grouped under parent with `id — title (fragment s1)`, rejected count); **HAPPENED** (port `--render-happened-row`: `at  type  detail`, with the turn-commits summary `N commit(s) in window: repo sha7 author: subject | …`, the intent summary, the text summary cut at 80 chars, or the event name; empty → "(nothing between this turn and the next)"); then ports (port `--render-ports` and `--ports-age`: `closed:` and `still open:` lists, age in minutes from `since` to the turn's `at`, `<1m` under a minute); then **MEMORY**.
4. **MEMORY** is new. When `frame.memory` is present, render `memory.calls[]` as `round  tool  args` with, under each, `reached: name, name` from `call.reached` (string array), and `memory.injected[]` (string array) as `injected before round 1: …`. When `frame.memory` is absent, print exactly: `no recorded memory call for this turn (nothing reached it that the record can show)`. Absence is a sentence, never a blank.
5. **Keys and links.** `n`/`→` next, `p`/`←` previous, `Home`/`End`, `g` refetch (live mode only; in fixture mode say so). `?frame=<i>` deep-links (1-based) and the URL updates as you step (`history.replaceState`). The SAID heading is a link to `../scopes/index.html?turn=<record.turn_id>` when `record.turn_id` is present (that is the RET-visit-turn analogue); otherwise plain text.
6. **Nothing of Emacs, 象 internals, git or minus40 beyond the fields above.** The rewind commands (`r`, `R`) are not ported: say in a one-line footer "rewind: Emacs only".

Export the pure parts so the test needs no DOM: `readyFrames(frames)`, `frameModel(frame)` → a plain object with every rendered string already computed (section by section), `happenedDetail(row)`, `portsAge(since, at)`, `cuePieces(text, cues)` (the text split into `{text, cue:boolean}` pieces; code points, `Array.from`), and `renderStepper(frames, host, opts)` returning `{goTo(i), next(), prev(), index(), count()}`. Types in the same file (a `Frame` interface and friends; keep them honest to the fixture: everything optional that the docstring says is optional). Around 350 lines of TypeScript plus a small stylesheet inside `index.html`. No dependencies.
