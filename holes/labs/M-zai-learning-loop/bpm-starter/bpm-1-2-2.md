# BPM 1.2.2 (Sp90)
Let the real valued function $f$ on $[0,1]$ have the following two properties:
1. If $[a,b] \subset [0,1]$, then $f([a,b])$ contains the interval with endpoints $f(a)$ and $f(b)$ (i.e., $f$ has the Intermediate Value Property).
2. For each $c \in \mathbb{R}$, the set $f^{-1}(c)$ is closed.

Prove that $f$ is continuous.
