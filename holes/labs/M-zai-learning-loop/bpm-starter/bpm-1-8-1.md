# BPM 1.8.1 (Sp81)
Let $f : [0,1] \to \mathbb{R}$ be continuous with $f(0) = 0$. Show there is a continuous concave function $g : [0,1] \to \mathbb{R}$ such that $g(0) = 0$ and $g(x) \ge f(x)$ for all $x \in [0,1]$.
(A function $g : I \to \mathbb{R}$ is concave if $g(tx + (1-t)y) \ge t g(x) + (1-t) g(y)$ for all $x$ and $y$ in $I$ and $0 \le t \le 1$.)
