## math-formalization/query-memory-with-api-names-not-obstacle-prose

When a formalisation proof stalls and the memory corpus is searched with
obstacle-vocabulary prose (the shape of the difficulty), queries often
return nothing even though the corpus holds the exact API recipe — the
recipe is indexed by lemma and constructor names, not by the stumbler's
description of the wall. Query with the suspected API names and lemma
shapes as soon as any are known, and when obstacle-prose queries miss
twice, grep the library source for the area's lemma names immediately:
the names that come back are simultaneously the proof plan and the
retrieval key that finds prior work. The measured cost of the opposite
order is a full independent solve of a problem the corpus had already
solved.
