# Codex Scribe pattern library — f77

These patterns were added because reviewed mathematics-memory search found no
coherent parent for the certified Kummer-extension moves.

## math-formalization/refute-a-prime-power-base-root-via-root-of-unity-ratio

- **Trigger:** To use a prime-binomial irreducibility criterion, one must show
  that a coefficient has no `p`th root in the base field, while the available
  hypothesis instead says that a chosen `p`th root in an extension is not in
  the algebra-map range.
- **Move:** Assume a base-field root `b`.  After disposing of `b = 0`, form the
  ratio of the extension root to `algebraMap b`; its `p`th power is one.
  Enumerate the `p`th roots of unity using a primitive root already in the
  base field, so the ratio equals a power of that primitive root.  Rearranging
  then expresses the chosen extension root as the algebra-map image of a
  base-field element, contradicting the range hypothesis.
- **Why it works:** The root-of-unity ambiguity between two `p`th roots is
  already defined over the base field when it contains a primitive `p`th
  root, so existence of any base-field root forces every extension root to
  descend.

## math-formalization/install-splitting-field-on-a-simple-radical-adjoin

- **Trigger:** Kummer APIs require an `IsSplittingField` instance, but the
  desired extension is presented concretely as the intermediate field
  generated by one radical rather than as an abstract splitting field.
- **Move:** Work in the adjoin subtype and prove the generator is a root of
  `X ^ p - C a`.  Obtain splitting from the primitive-root factorization.
  For the generation half of `isSplittingField_iff_intermediateField`, show
  the adjoin of the generator inside its own simple adjoin is top, then bound
  that adjoin by the adjoin of the full root set.  Once the instance is
  installed, use the standard Kummer Galois and automorphism equivalence APIs.
- **Why it works:** A polynomial that splits and whose root set contains a
  generator of the whole subtype has root-set adjoin equal to top, exactly
  matching the library characterization of a splitting field.

## math-formalization/orient-an-automorphism-equivalence-through-its-inverse

- **Trigger:** A library equivalence classifies automorphisms by exponents,
  but its pointwise action theorem is stated for the inverse image of a group
  parameter while the goal starts with an arbitrary automorphism.
- **Move:** Rewrite the arbitrary automorphism as `e.symm (e sigma)` using
  `e.symm_apply_apply`, then apply the inverse-direction pointwise theorem at
  the parameter `e sigma`; normalize only the scalar-action notation needed
  by the goal.
- **Why it works:** Surjectivity is already packaged in the equivalence, and
  rewriting through the inverse avoids manually reconstructing or comparing
  the exponent chosen for the automorphism.
