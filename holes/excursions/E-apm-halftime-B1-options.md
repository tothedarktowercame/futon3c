# B1 discovery — pattern and memory taxonomy options

The measured gap is structural: recall traverses reviewed `memory/assert`
attachments, while a flexiarg's existence as a `pattern/library` entity does
not itself make that pattern recallable. Only 3 of 75 mathematics patterns are
currently named by any memory edge. This note proposes no backfill and creates
no edges.

## Option 1 — converge through reviewed attachments

Treat every recallable pattern as a reviewed-memory endpoint. The Scribe or a
promotion tool proposes an attachment from concrete correction evidence; an
independent reviewer accepts or rejects it through the existing memory
lifecycle. The cost of closing today's gap is not “72 writes”: it is up to 72
evidence-to-pattern mapping decisions, up to 72 independent reviews, rejected
and ambiguous cases, and a canary proving dispatch projection. Person-time
cannot be estimated honestly until a representative sample is reviewed.

**Tradeoff:** this preserves the current warrant model, but patterns with no
earned memory remain intentionally unreachable. A completeness target of
75/75 would pressure reviewers to manufacture weak attachments.

## Option 2 — keep taxonomies separate

Let pattern retrieval query `pattern/library` entities directly, scoped by
`:domain`; reserve reviewed `memory/assert` edges for durable experiential
memory. Under this interpretation B1 is misfiled: the defect is the absence of
a direct pattern-retrieval path, not 72 missing attachments.

**Tradeoff:** all reviewed flexiargs become candidates without invented memory
evidence, but the caller must distinguish a lexical pattern proposal from a
warranted memory result. Conflating those outputs would weaken the review gate.

## Option 3 — hybrid nomination and warrant

Retrieve pattern entities directly as nominations, then enrich them with any
reviewed attached memories. A pattern may surface without memory support, but
the response labels that state explicitly; only reviewed attachments may
contribute memory advice or claims of learned experience.

**Tradeoff:** this best matches the stated research line—Scribe-extracted
rewrite rules are learned memory, while flexiargs are a broader technique
library—but it introduces two result classes that every consumer must preserve.

## Decision required

Joe must rule whether “recallable pattern” means “reviewed flexiarg,” “pattern
with reviewed experiential support,” or both as explicitly different result
classes. Until then, attachment coverage is a diagnostic count, not a target.
Mass-creating the 72 absent edges would prejudge that decision and bypass the
separation-of-powers review contract.
